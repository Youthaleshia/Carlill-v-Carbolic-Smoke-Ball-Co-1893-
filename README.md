# Carlill-v-Carbolic-Smoke-Ball-Co-1893-
This case deals with a company’s advertisement promising a reward, which was held to be a valid unilateral contract when accepted through performance.
# Key Learning Outcome:
Understanding unilateral contracts and acceptance through conduct without formal communication.
# Key Takeaway:
A public advertisement can become legally binding if it is clear, definite, and shows intention.
